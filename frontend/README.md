# CommunityHub Frontend

Vite + React frontend for the IYF Season 12 CommunityHub team project.

## Commands
- `npm install` — install dependencies
- `npm run dev` — start Vite development server
- `npm test` — run Vitest unit tests
- `npm run build` — create production build

## Structure
- `src/components/` — Header, Footer, Sidebar, CreatePost, PostList
- `src/utils/` — pure helper functions and tests
- `src/exercises/Anthony-mugwe/` — individual Week 8 React exercises
- `src/App.jsx` — app state and page composition

The initial Week 8 implementation uses `useState` for posts. It does not yet include backend persistence or authentication.
