# GitHub Issues to create

Create each item below as a separate GitHub Issue in the shared team repository. Assign an owner and use the issue number in the relevant pull request.

1. **[MVP] User profiles** — profile data, profile page and profile editing.
2. **[MVP] Posts** — create and read posts; later connect to the API.
3. **[MVP] Comments** — add and read comments on posts.
4. **[MVP] Authentication** — registration, login, logout and protected pages.

Suggested PR description footer: `Closes #<issue-number>` only when the PR really closes that issue.
